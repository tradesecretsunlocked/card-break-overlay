CHASER CARD IMAGE FILENAMES
Drop one image per chaser into this folder (cards/). PNG, about 3:4 portrait (for example 600 x 840). Any chaser without a file shows a generated card face, so nothing breaks.
To use a different filename or a web address, put it in the Image column of the Spots screen.
