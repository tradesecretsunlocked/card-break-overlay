WHAT DO YOU CALL A SPOT?
BOX 1
Count sets how many spots this product's board shows. One Piece and Weiss Schwarz run 12 to a case, Union Arena runs 16. The count is saved per product, so each one keeps its own size. Changing it rebuilds the board and clears sold marks for that product.

Spot word is just what the tiles and the sold list call each spot — BOX 1, SPOT 1, TILE 1. It applies to every board, changes nothing underneath, and keeps all your sold marks. Automation still matches a listing titled "Spot 4" either way.
Board background per layout
Browse to a JPG or PNG for each board. Images are resized to fit (up to 2560px) and compressed automatically; transparency is preserved when the picture actually uses it. Stored in this browser, so they survive reloads and OBS restarts. Clear puts the default back.

Art storage used: 0 KB across all slots. Artwork is kept in IndexedDB, which allows far larger files than the old limit — if you were told a picture was too large before, try it again. Existing backgrounds are moved over automatically the first time this overlay loads.
